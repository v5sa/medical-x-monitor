## Planned Scripts

### x_signal_collector.py
- Scrape X posts using defined search operators
- Parse and categorize signals

### weekly_digest_generator.py
- Aggregate signals from the week
- Generate markdown digest
- Post to archives/

### competitor_tracker.py
- Monitor key competitor X accounts
- Flag product launches, partnerships, recalls
- Alert on high-priority signals

### regulatory_alert.py
- Monitor FDA, NMPA, EU regulatory accounts
- Parse clearance/recall announcements
- Categorize by product relevance

## Requirements
- Python 3.10+
- Playwright (for X scraping)
- GitHub API (for Issue creation)
- Tweepy or similar (if using X API)
