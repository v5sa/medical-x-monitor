# Contributing to medical-x-monitor

This is an internal V5 Medical repository managed by the Office of the CEO.

## How to add a new signal
1. Create a new Issue using the Signal template.
2. Always include the original X post URL.
3. Write a concise summary and note why it matters to V5.
4. Apply the correct labels.
5. Link the Issue to the relevant workstream folder if needed.

## Updating documentation
- Keep `/docs/key-accounts.md`, `/docs/hashtags-keywords.md`, and `/docs/search-operators.md` current.
- Review lists at least quarterly.

## Weekly digests
Place completed weekly summaries in `/archives/YYYY-WXX-digest.md`.

Thank you for helping keep V5’s industry intelligence organized and actionable.
